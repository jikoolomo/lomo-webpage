# LOMO Links 개선 내역

## 배포 안정성

오디오 소스를 `/manus-storage/` 절대 경로에서 `audio/` 상대 경로로 변경했습니다. 이제 `audio/` 폴더를 웹페이지와 함께 GitHub Pages 배포 루트에 업로드하면 자연음 파일을 찾을 수 있습니다.

인트로·히어로·생태계 카드·LOMO House 모달에서 사용하는 사진을 `images/` 폴더에 포함했습니다. 페이지 핵심 이미지가 외부 이미지 서버 상태에만 의존하지 않도록 했으며, 사용자의 사진으로 교체할 때도 파일명을 유지하거나 CSS의 경로만 바꾸면 됩니다.

## 사용자 경험과 접근성

사운드 버튼의 선택 상태를 브라우저 저장소에 저장하고, 이전에 사운드를 허용한 방문자는 첫 사용자 상호작용 이후 선호 상태를 복원하도록 했습니다. 오디오 로딩 오류가 발생하면 사운드를 안전하게 끄고 버튼 상태를 갱신합니다.

공유 미리보기용 Open Graph와 Twitter 메타데이터, 작성자 정보, 이미지 연결을 추가했습니다. 히어로 이미지는 우선 로딩하도록 설정했고, 새 탭으로 열리는 외부 링크에는 `noopener`를 추가했습니다.

인트로가 열려 있을 때 본문 스크롤이 발생하지 않도록 잠금 처리했으며, 브랜드·Route Studio·푸터 링크에도 키보드 포커스 표시를 추가했습니다. 기존의 `prefers-reduced-motion`, 모달 Escape 닫기, 포커스 복원 동작은 유지했습니다.

## 검증 결과

`script.js`는 Node 문법 검사를 통과했습니다. 네 개 오디오 파일은 로컬 공개 미리보기 서버에서 HTTP 200으로 응답했고, 인트로 재생 URL(`?intro=1`), 인트로 건너뛰기, 메인 화면 전환, LOMO House 모달 열기·닫기, 사운드 버튼 상태 변경을 브라우저에서 확인했습니다.

## 배포 구성

GitHub Pages에는 다음 항목을 배포 루트에 함께 업로드합니다.

| 항목 | 설명 |
|---|---|
| `index.html` | 페이지 구조와 콘텐츠 |
| `styles.css` | 시각 디자인과 반응형 스타일 |
| `script.js` | 인트로·사운드·모달 상호작용 |
| `audio/` | 네 가지 자연음 MP3 |
| `images/` | 페이지에서 사용하는 로컬 사진 |
